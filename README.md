# Linux CLI Tool (Bash) – Phase 1

A menu-driven command-line application built using Bash scripting on Ubuntu.  
This project combines multiple scripts into a single interactive system to handle utilities and file operations.

---

## Features

- Menu-based navigation  
- User input handling and validation  

### Utilities
- Say Hello  
- Check Age  
- Show Date  
- Calculator (Add, Subtract, Multiply, Divide)  
- Even/Odd Checker  
- Guess Number Game  

### File Operations
- Create file  
- Read file  
- Delete file  
- Rename file  

---

## Technologies Used

- Bash scripting  
- Linux (Ubuntu VM)  

---

## Project Structure

file-handling/
- create_file.sh  
- read_file.sh  
- delete_file.sh  
- rename_file.sh  

menu.sh

---

## Problem

Managing file operations through the command line can be repetitive and unstructured.

---

## Steps Taken

- Built separate scripts for each operation  
- Implemented input validation  
- Added confirmation prompts for deletion  
- Combined scripts into a menu-driven system  

---

## Solution

Developed a Bash-based CLI tool that integrates file operations and utilities into a single interactive system.

---

## Result

Successfully built a working command-line tool with modular design and menu-based interaction, improving usability and workflow efficiency.
